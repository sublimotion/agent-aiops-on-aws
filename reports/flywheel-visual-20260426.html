Verification Flywheel — Experiment Results

autoresearch / verification-flywheel  ·  2026-04-26  ·  CoderForge-Preview (1,600 traces)

Hypothesis

A cheap classifier (RF) can bootstrap itself from expensive LLM verifier labels, progressively handling more evaluations for free and reducing evaluation cost by 10×.

This is the same pattern Shopify uses for their Flow agent: production data flows to an LLM judge, which generates training labels for a cheaper fine-tuned model (Qwen3-32B), retrained weekly on 2× H200. As the cheap model improves, it handles more traffic, and the expensive judge is called less often.

We test whether this flywheel works for code patch verification: can an RF classifier trained on silver labels from a Haiku-based content verifier progressively take over evaluation of agent trajectories, and does this transfer to out-of-distribution data?

Methodology

Phase 1: Cold Start
Run cascade without RF on 200 CoderForge trajectories. All traces go through Multiprompt Haiku (Tier 1) or Debate (Tier 2). Use cascade verdicts as silver labels to train the initial RF.
Phase 2: Flywheel
Run 5 cycles of 200 traces each, cascade with RF. RF handles confident cases for free; uncertain cases escalate to Haiku. After each cycle, retrain RF on all accumulated silver labels. Measure cost reduction.
Phase 3: OOD Transfer
Test RF trained on SWE_Rebench (1,200 traces) against SWE_Smith (different repos, different distribution). Measures whether learned features generalize across dataset splits.
Dataset

CoderForge-Preview — 155K Docker-verified agent trajectories across 1,655 repos (Together AI). Splits: SWE_Rebench, SWE_Smith, R2E_Gym. Each trajectory has a binary reward field (0/1) verified by Docker test execution.

Key Terminology

Gold Labels
Docker-verified test execution results from CoderForge. The ground truth: did the agent's patch actually pass the test suite?
Silver Labels
Cascade verdicts from Haiku content verifier. Cheaper than Docker but noisier (68% agreement). Used to train the RF without running tests.
RF Classifier
Random Forest using 4 behavioral features extracted from the agent trace. Free (<1ms), runs on CPU. The "cheap model" in the flywheel.
