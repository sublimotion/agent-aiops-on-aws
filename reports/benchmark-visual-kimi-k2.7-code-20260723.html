TLDR

PASS T4 (TP4+DP2 + prefix cache) delivers 3,335 tok/s @ c192 with TTFT p95 2.48s — 6× headroom under the 15s interactivity gate — at $3.33/M output tokens [measured]. Prefix cache is the dominant lever (+225% at the dual-gate knee; TTFT p50 19.1→0.96s at c64); the layout adds +19% and halves TTFT again. The surprise: an OPEN upstream crash (vllm#49200 class — FA4-CuTe MLA prefill × prefix cache × Blackwell INT4) killed the default config twice; the working fix is the prefill-backend pin. The interactivity gate never binds after T2 — the tpot ≥ 40 floor is what decides the operating point (c32 @ 1,622 if enforced strictly). Quality gate 3/3.

Decision

  1. Adopt T4 (INT4 · prefix cache · TP4+DP2 · FLASHINFER_MLA + FLASHINFER prefill pin · kimi_k2 parsers + --enable-auto-tool-choice) at c192/node for the TTFT-15s contract [measured: 3,335 tok/s, p95 2.48s, 0 err, quality 3/3].
  2. Open to operator: if tpot_p50 ≥ 40 is a hard per-stream floor (not just an invariant at the reported knee), operate at c32/node (1,622 tok/s, stream 52) — 2× fleet cost. The TTFT-15s directive implies the aggressive reading; confirm before fleet sizing (~10 nodes @ c192 vs ~20 @ c32 for 32.5k tok/s).
  3. Avoid: default FA4-CuTe MLA prefill with prefix cache on Blackwell K2-family INT4 [measured: engine-fatal crash, vllm#49200 class — both FLASHINFER_MLA-default and CUTLASS_MLA die; only the prefill-backend pin works].
  4. Follow-ups: T3 drafter sweep (waste 1.48 favorable — num_speculative_tokens (2, 3)); c256+ ceiling; T5 MNBT; SGLang arm (cannot run EAGLE3-MLA drafts — a vLLM moat for this model); same-harness K2.6 comparison.

Caveats & provenance

  • Prefill-backend confound: T2/T4 measured with FLASHINFER prefill, T0 with default FA4-CuTe — forced by the upstream crash, not chosen. Effect bounded by the 92% cache hit (prefill ≈ 8% of tokens on cached arms). T0 re-anchor on the pinned backend deferred [inferred: T2 delta slightly overstated by whatever the prefill backends differ on the remaining 8%].
  • tpot at c192: stream p50 20.3 tok/s is below the 40 floor — the winner satisfies the TTFT gate, not the strict floor (Decision #2).
  • Output length: swept at ≤1024 tok (budget); the card workload declares ≤4096 run-to-eos — longer outputs shift TPOT down and E2E up at fixed c [inferred].
  • cached_tokens telemetry: v0.25 streaming responses do not populate prompt_tokens_details; cache effectiveness evidenced by the TTFT collapse (19.1→0.96s p50 @ c64) rather than per-request counters. KV-eviction check at c≥64 therefore indirect this session.
  • Ceiling unswept: T4 agg still rising at c192; the true TTFT-gate knee is ≥c192 (budget exit, not plateau).
