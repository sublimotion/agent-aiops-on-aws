K Key Findings
✓

Zero-SPOF via NLB PROVEN

NLB targets only worker proxies (ray-node=worker). Head proxy excluded from load balancing. Head pod death (T3) causes zero errors — 14,542 requests served without a single failure. The architecture has no single point of failure.

✓

GCS Fault Tolerance Works PROVEN

Workers survived head pod crash with 600s reconnect timeout. GCS state fully restored from ElastiCache Serverless in ~3 minutes. KubeRay v1.3.0 automates head recreation and GCS restore. Zero serving interruption during recovery.

✓

stunnel TLS Sidecar PROVEN

Ray's C++ Redis client lacks TLS support. ElastiCache Serverless enforces TLS. Solution: Alpine stunnel sidecar on every pod proxying localhost:6380 → ElastiCache TLS. ~2s init, minimal resource overhead.

✓

Graceful Node Drain PROVEN

Node drain (T2) produced only 6 errors (0.04%) in a 0.2s window. kube-proxy iptables endpoints updated almost instantly. Surviving worker absorbed full load. Best achievable result for infrastructure-level disruption.

M Test Methodology
Traffic Path

Dedicated traffic-client pod on system node → NLB ClusterIP (yolo-ft-nlb) → kube-proxy iptables → worker proxy endpoints. In-cluster only — no port-forward, no external hostname.

Fault Injection

Faults injected from local machine via kubectl exec/delete/drain. Traffic and faults decoupled — traffic client never affected by fault injection. Each test: 60s warmup, then fault at t=60s.

Load Profile

50 req/s sustained, 240-300s per test. JSON payload with base64-encoded 8x8 RGB PNG (pure Python generation, no PIL). aiohttp with force_close=True for per-request LB distribution.

! Failures & Fixes
TLS

TLS Incompatibility

Ray C++ Redis client doesn't support rediss://. ElastiCache Serverless enforces TLS. Fix: stunnel sidecar on every pod. Use port 6380 (not 6379) to avoid conflict with Ray GCS server port. Set RAY_REDIS_ADDRESS=127.0.0.1:6380.

DEPS

numpy Dependency Conflict

numpy>=2.0 breaks pyarrow in Ray CPU image (compiled against numpy 1.x). Error: _ARRAY_API not found. Fix: pin numpy<2 in runtime_env pip list. Head also needs it because build_app imports the deployment module.

DISK

Disk Pressure

pip install of ultralytics + torch consumes ~8-12GB ephemeral storage. Default 20GB EBS caused pod eviction. Fix: system nodes need 50GB+ EBS (disk_size = 50), head pod needs ephemeral-storage: 20Gi request / 30Gi limit.

LIB

Missing libGL Shared Library

libGL.so.1 missing in Ray CUDA images. OpenCV (via ultralytics) requires it. Fix: debian:bookworm-slim init container copies libGL/libGLX/libGLdispatch/libglib to shared emptyDir. Worker sets LD_LIBRARY_PATH=/shared-libs.
