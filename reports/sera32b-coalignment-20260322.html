Key Insights

1. SVG training is harness-model co-alignment. SERA-32B learned SERA's interaction protocol (explore, targeted edit, verify) from successful SVG trajectories. It's the only model where SERA harness outperforms OpenCode (64% vs 54%).
2. Single-harness SFT destroys generality. SWE-agent-LM trained on only SWE-agent trajectories: -30pp from base. The model learned open/goto/scroll so narrowly it fails everything else.
3. Inference-time diversity beats training-time specialization. SERA-32B x SERA = 64%. Base Qwen3.5 x {SERA+OpenCode} = 96%. Ensembling across harnesses with a general model wins — for now.
4. The fragmented ecosystem makes this hard. No two harnesses share tool names, schemas, or interaction patterns. Training on one dialect narrows the model; training on none wastes potential.
5. Each harness adds unique passes. 8-harness ensemble (36%) has 6 unique passes across 4 harnesses. Droid contributes 2 from previously unsolved repos (pylint, seaborn).
6. Multi-harness trajectory training is the path forward. Train on 3-4 diverse harness trajectories simultaneously. The model learns intent (explore, locate, fix, verify) not syntax (edit_file vs Edit vs sed).
