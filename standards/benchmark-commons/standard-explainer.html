One format, every producer

The v1 benchmark-commons envelope is the shared output contract for LLM inference benchmarks in this repo. Producers (vLLM bench-serve, SGLang, AIPerf, GenAI-Perf, guidellm, LLMPerf, recon-perf, bench-standard.py) emit the same structure. Consumers (compare.py, the results-vault dashboard, benchmark-analyst agent, Grafana/Athena/CloudWatch) read one format. The envelope captures model identity, engine config, deployment context, workload card, full latency distributions, SLO evaluation, and optional extensions (GPU telemetry, cost, speculative-decode stats, reconciliation).

Workload cards ()

Each artifact references one workload card via workload.catalog_id. Cards live in standards/benchmark-commons/workloads/. Multiple engines and hardware targets produce comparable results only when they share a catalog_id.

Core metric contract — definitions

Every latency metric uses the same shape: {mean, p50, p90, p95, p99}. All in milliseconds. Use null for percentiles the producer did not capture — do NOT invent values. min/max/std belong in extensions.latency_detail.

Metric Definition Unit
ttft_msTime from request send to first token received.ms
tpot_ms(e2e - ttft) / (output_tokens - 1) — excludes first token.ms
itl_msMean time between consecutive token arrivals.ms
e2e_msTotal request latency from send to last token.ms
output_toks_per_stotal_output_tokens / duration_s. Legitimately 0 for embedding/classifier workloads.tok/s
request_throughputcompleted / duration_s. Primary metric for embedding workloads.req/s
total_toks_per_s(total_input + total_output) / duration_s.tok/s

Producer checklist — minimum viable v1 envelope

If you're writing a producer or consumer, get these right first

  • Emit schema_version: "1.0.0" and a fresh UUIDv4 artifact_id per run.
  • Populate all required top-level blocks: source_tool, model, engine, infrastructure, workload, metrics.
  • Under metrics, every one of ttft_ms, tpot_ms, itl_ms, e2e_ms is required with {mean, p50, p90, p95, p99} — all ms.
  • If a latency percentile is not measured, emit null rather than inventing a value. Consumers detect and honour null. Invented values corrupt cross-team comparisons.
  • Populate output_toks_per_s and request_throughput — both are required. For embedding / classifier workloads, output_toks_per_s is legitimately 0; use request_throughput as the primary metric.
  • Set workload.catalog_id to a known card (see grid) — this is what makes artifacts comparable across teams. Use catalog_id: null only for custom workloads (see Appendix A in PROPOSAL.md).
  • Compute slo.results[*].pass as actual ≤ target strictly. A null actual means pass: null, never true.
  • Name output files as {model}_{substrate}_{instance}_{engine}_{workload}_{timestamp}.json — every field separated by underscores.
  • Scrape engine /metrics to populate extensions.gpu_telemetry and extensions.cache_stats. Client-side timing alone loses TTFT, KV cache, and queue-wait info. bench-standard.py does this for you.
  • Validate with python3 container/validate-artifact.py artifact.json before committing or publishing.
