Standards & Commons — How It All Connects

agent-aiops-on-aws  ·  deterministic resolver tier  ·  2026-06-01
The repo has a shared “commons” tier under standards/ that turns hard-won operational knowledge into deterministic, fail-closed code an LLM cannot reinterpret. Two packages follow the identical shape — declarative input → pure compiler → registry of rules → raises on invalid → conformance test — and they are wired into the agents, skills, specs, and steering files that drive every deployment and benchmark. This report maps those connections.
