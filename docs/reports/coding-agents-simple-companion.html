Methodology and Assumptions

The calculator separates demand from measured capacity, and it only compares model-node pairs where we have benchmark evidence.

Demand

Tasks/day comes only from engineers, agents per engineer, and tasks per agent per day. Changing the model does not change the entered workload.

Capacity

Capacity is measured output goodput for the selected model-node pair multiplied by seconds/day, then divided by output tokens/task.

Cost Basis

Self-hosted cost is GPU instance cost. The editable $/hr field is the selected node list price; frontier comparison uses cost per task from coding-agent benchmark economics.

Evidence boundary: model selection is intentionally tied to the hardware used in the benchmark. We should not imply GLM, Kimi, Qwen, or Devstral have equivalent goodput on every GPU node until those permutations are measured. The default frontier cost, $2.01/task, follows the Artificial Analysis cost-per-task basis: input, cached, and output token prices multiplied by actual coding-agent token usage, including cache write pricing and cache discounts where available.
