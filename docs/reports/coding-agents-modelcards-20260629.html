Open-Weight Coding Agents on Blackwell

Model cards + cost analysis for teams on Claude Opus / GPT-5.x evaluating self-hosted open-weight coding models · B200/B300 · compiled 2026-06-29
How to read this (start here). Most teams begin agentic coding on a frontier API (Opus, GPT-5.x) — it just works. As token volume grows, the bill grows with it, and agentic coding burns tokens (reasoning + multi-turn tool loops + repo context = 100K–1M+ tokens per solved issue). This report asks: can a self-hosted open-weight model do the work, and what does it cost? Each model gets a card (the TL;DR) with three things: (1) capability — the model author's official published benchmarks; (2) serving — what we measured running it on our own Blackwell GPUs; (3) cost — $/output-token at current spot and on-demand GPU prices. Detail sections follow the cards.
Every number is tagged by source: MEASURED we ran it (our GPUs) · OFFICIAL model author's HF card / tech report (self-reported, not independently verified) · LIST provider list price (Anthropic / OpenAI / AWS, current as of 2026-06-29)
Why there is no single "best model" leaderboard. Our serving runs used different hardware (B200/B300), quantization (FP8/NVFP4/FP4), parallel layouts, and — critically — different output lengths. Aggregate tok/s is dominated by output length, so the throughput numbers are not a model speed ranking; they tell you what a node delivers for that config. Capability numbers come from each vendor's own card, measured on their harness — vendor SWE-bench scores are not mutually comparable either (harness choice alone swung one model 38→88% in our tests). The cards exist precisely because a flat table would mislead. Treat each card as "what this model is for," not "rank #N."

The cost picture — current prices, grounded

Frontier API output price (per 1M output tokens), current list: Claude Opus 4.5–4.8 = $25 (the old Opus 4.1 $75 is deprecated), Sonnet 4.6 = $15, Haiku 4.5 = $5 · OpenAI GPT-5.5 = $30, GPT-5.4 = $15, GPT-5.2 = $14, GPT-5 = $10, GPT-5-pro = $120. On Bedrock, GPT-5.5 = $33 / GPT-5.4 = $16.50.
Self-hosted GPU cost (verified via EC2 pricing API, 2026-06-29): p6-b300.48xlarge = $23–38/hr spot (us-east-1 ~$23, us-west-2 ~$38), $142.42/hr on-demand/ODCR; p6-b200.48xlarge = ~$23/hr spot, $113.93/hr on-demand.
The honest multiplier. Self-hosting wins, but how much depends on the GPU pricing basis. Using GLM-5.2's measured 9,271 tok/s @ $0.69–1.14/Mtok (spot) vs $4.27/Mtok (ODCR): the gap to Opus ($25) is ~36× on spot but ~6× on ODCR; vs Sonnet/GPT-5.4 ($15) it's ~22× spot / ~3.5× ODCR; vs GPT-5 ($10) it's ~14× spot / ~2.3× ODCR. Production usually runs ODCR (spot can be reclaimed), so the defensible everyday number is ~2–7×, with spot as the best case. Either way the direction is clear against Opus-class; against the cheaper GPT-5 tier on ODCR the margin is real but not dramatic, and gets eaten if your GPUs sit idle.

Detail & caveats (for the careful reader)

  • Capability numbers are vendor-self-reported (HF cards / tech reports), each on the vendor's own harness — not independently verified and not mutually comparable. The one exception is GLM-5.2's 89%, which we ran on the same harness + issues as the Claude baseline. Harness choice alone swung a fixed model 38→88% in our agent-harness study, so cross-vendor SWE-bench comparisons are soft.
  • $/Mtok is output-token only, = (GPU $/hr) ÷ (measured output tok/s × 3600 / 1e6). It excludes input tokens, prompt-cache economics, and ops overhead. Blended $/solved-task on your real input:output mix is the number that should drive the decision.
  • Spot vs ODCR matters more than the model: B300 spot ranges $23 (us-east-1) to $38 (us-west-2); ODCR is $142.42. Production usually can't tolerate spot reclaim, so the everyday basis is ODCR → the realistic savings vs frontier is ~2–7×, with spot as best-case (~14–43×).
  • Throughput is config-specific, not a model ranking — different OSL/quant/layout/HW per run. The Nemotron $16.81 ODCR figure is inflated by a TP4 config that billed a full node for 4 idle GPUs; a packed layout would roughly halve it.
  • Some HF cards contain forward-dated content (2026 competitor references). We report the cards' own published figures verbatim; treat as vendor claims pending independent eval.
  • Bedrock note: OpenAI models on Bedrock bill through AWS and differ from direct OpenAI (GPT-5.5 $33 vs $30, GPT-5.4 $16.50 vs $15). Current Anthropic Opus is $25 output (Opus 4.1's $75 is deprecated/retired).
