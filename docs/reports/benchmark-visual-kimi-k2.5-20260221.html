Key Findings

Generation-bound, not prefill-bound

Throughput is flat at 11 tok/s regardless of context length (16K–48K). Marlin MoE kernel dominates token generation. Prefill cost is a small fraction of E2E at 150-token outputs.

No prefix caching benefit in multi-tenant

50-tenant workload shows 1.00× cold/warm speedup. Each tenant has a unique system prompt — baseline vLLM's prefix cache doesn't help. This is where KV offloading should provide value.

GDS unavailable on AL2023

nvidia-fs kernel module not in AL2023 EKS AMI. LMCache must use POSIX mode (CPU-mediated I/O). Eliminates the GDS advantage that motivated the FSx + LMCache architecture.

Model loading is compute-bound

64-shard INT4 MoE takes ~2 hours regardless of NVMe or FSx. Marlin MoE kernel repacking per shard is the bottleneck, not I/O bandwidth.
