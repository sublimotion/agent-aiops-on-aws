Key Findings
Blackwell Works Out of the Box
vLLM 0.15.0 (cu130) runs on RTX PRO 6000 Blackwell (sm_120) without custom builds. FP8 quantization, prefix caching, and TRITON MoE backend all functional.
Per-GPU Parity with H200
455.2 tok/s per GPU on g7e vs 451.6 on H200. Blackwell GDDR7 achieves equivalent per-GPU throughput despite lower memory bandwidth (1.5 vs 4.8 TB/s).
MTP Hurts on PCIe GPUs
Speculative decoding (MTP, 2 tokens) degrades throughput 2–41% across all QPS levels. PCIe inter-GPU overhead exceeds speculative gains. Use baseline config on g7e.
Mamba Hybrid Architecture Constraints
Qwen3-Next is attention+mamba hybrid. MTP incompatible with mamba cache 'align' mode in v0.15.0. Prefix caching works but is experimental for mamba layers.
4.6x Cost Efficiency
$1.06/M output tokens on g7e.24xlarge vs $4.88/M on p5en.48xlarge. At $8.27/hr vs $63.30/hr, Blackwell delivers massive savings for equivalent per-GPU work.
Concurrency Limited by GPU Count
4 GPUs can't match 8-GPU H200 at 1000 concurrent 10K-token requests (10M total tokens vs 2.76M KV cache). Scale to g7e.48xlarge for high-concurrency workloads.
