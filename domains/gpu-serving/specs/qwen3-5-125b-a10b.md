# Qwen3.5-125B-A10B — CTO Benchmark Model #1

## Status: DRAFT (2026-05-13)

## Overview

Primary workhorse for the CTO benchmark engagement — MoE LLM (125B total / 10B active) chosen to exercise KV cache scaling, long context, and the full quantization Pareto.

Parent engagement: `cto-benchmark-engagement.md`. All runs here emit manifests against that spec's schema and obey its statistical rules.

**Stand-in policy**: if Qwen3.5-125B-A10B is not available on Hugging Face when the engagement starts, use Qwen3-Next-80B-A3B on the same infra and flag the substitution in every manifest (`cloud_equivalence_note: "stand-in for Qwen3.5-125B-A10B"`). Existing Qwen3-Next blueprint: `blueprints/qwen3-next/`.

## Components

### 1. Compute

- **Platform**: EKS 1.32
- **Instance types**:
  - Primary: `p5en.48xlarge` (8× H200, NVSwitch) — us-east-2c
  - Alternate: `p6-b200.48xlarge` (8× B200, NVSwitch) — capacity-block
  - Stand-in: `p5e.48xlarge` (8× H200) if p5en unavailable
- **Scaling**: single-node for O1/O3/O9; min=1 max=2 for O5 burn-in

### 2. Model

- **Model ID**: `Qwen/Qwen3.5-125B-A10B-Instruct` (or stand-in: `Qwen/Qwen3-Next-80B-A3B-Instruct`)
- **Architecture**: MoE, hybrid attention (linear + full)
- **Format**: BF16 baseline, FP8 (E4M3), INT8, INT4 — one checkpoint per precision
- **Serving**: vLLM nightly (`vllm/vllm-openai` with `transformers==4.57.1+` for Qwen3.5 support)
- **Deployment card**: run `mdc get qwen3-5-125b-a10b --engine vllm` before deploying; the card's `tiers:` block carries the canonical per-tier configs (quant format, MoE TP constraints, attention backend). Use `mdc tiers:refresh` to validate recommendations against latest upstream before a new deployment. Do not re-inline tier advice in this spec.

### 3. Networking

Standard EKS VPC; EFA on p5en.

### 4. Storage

- `/mnt/nvme` for weights (one subdirectory per precision)
- S3 mirror of all calibration + eval datasets (Appendix A rule: no live downloads)

## Verification criteria

Standard template Stages 4a–7 apply. Engagement-specific additions:

### Stage 6 — Benchmark
- [ ] All O1 cells at CV ≤ 0.05 on throughput
- [ ] O3 quality gate runs BEFORE throughput capture for every non-BF16 precision
- [ ] O11 sampler logs both DCGM and nvidia-smi (cross-check per doc rule)
- [ ] O5 drift within ±2% from hour-1 steady state
- [ ] Tier Stack Table filled (T0–T5) per `docs/optimization-stack.md`, with deltas measured against T0 baseline
