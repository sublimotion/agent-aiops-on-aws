Gotchas Discovered During Validation

! Shared Memory Name Mismatch
LMCache defaults to shared_memory. ai-toolkit uses ai_toolkit_cache. Must set via both kv_connector_extra_config AND LMCACHE_CONFIG_FILE (adapter reads config.extra_config, not vLLM-level config).
! UID Mismatch on /dev/shm
ai-toolkit creates shm as uid 1000 with 0600. vLLM runs as uid 2000. Fix: chmod 666 /dev/shm/ai_toolkit_cache. Production: unify UIDs or use supplemental GID.
! Env Var Ordering
K8s $(VAR) substitution only resolves vars defined earlier in the env list. NODE_IP must appear before LMCACHE_REMOTE_URL.
! hostPath, Not emptyDir
Must use hostPath: /dev/shm (not emptyDir with medium: Memory) to share POSIX shm with the ai-toolkit daemon running on the host.
! FSx Root Permissions
HyperPod-managed FSx root is 755 root:root. vLLM (uid 2000) can't write. Create subdirectory: mkdir -p /mnt/fsx/kvcache && chmod 777 via init container.
~ EKS 1.32 Required
RestrictedInstanceGroups (system nodes for operator pods) not supported on K8s 1.33. Inference clusters must target EKS 1.32.
