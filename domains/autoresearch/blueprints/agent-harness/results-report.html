Key Insights

Main findings from the two experimental phases.

Parkinson's Law for Agents

The model consistently delays its first edit to the final third of available turns (65% of budget for 10 turns, 58% for 30 turns). More turns means more procrastination, not more exploration.

Context Compaction Actively Hurts

Config F (compact at turn 15) achieves only 40% fix rate -- worse than Config A (10 turns, 36% budget-normalized). Compaction strips exploration context and the model re-reads files, entering a loop. 41.3% repeat rate is the worst across all configs.

Ensemble Is the Biggest Win

Running SERA + LangGraph and taking the union lifts pass rate from 14-16% to 22% (37-57% improvement). The harnesses solve different issues because SERA's turn pressure forces earlier, different patches than LangGraph's natural exploration.

Fix Generation Does Not Equal Quality

LangGraph generates 62% fixes but only 14% pass (23% conversion). SERA generates 46% fixes but 16% pass (35% conversion). More diffs does not mean better diffs. Precision and recall trade off across scaffolding strategies.

Scaffolding Has Converged at 14-16%

Neither harness alone exceeds 16% pass rate. Phase 3 (finetuning) may now be relevant -- a targeted LoRA on common error patterns could compound with the ensemble approach. Full SWE-bench evaluation with Docker is needed to assess the true ceiling.
