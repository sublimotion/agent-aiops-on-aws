Request Flow

1
User invokes research tool — types a query in Claude Desktop or Claude Code. The MCP client calls research(query).
2
mcp-proxy.py (local) — receives the MCP JSON-RPC message over stdio. Handles initialize, tools/list, and ping instantly from local state. Only tools/call goes to AWS.
3
invoke_agent_runtime — boto3 SigV4-signed HTTP POST to AgentCore Runtime endpoint research_agent_endpoint (liveVersion 23). Timeout: 1200s, no retries.
4
server.py receives POST /invocations — loads secrets at startup (BRAVE_API_KEY from Secrets Manager), calls run_query() via claude-agent-sdk.
5
Lead Agent orchestrates — Claude Opus 4.6 spawns Researcher, Data Analyst, and Report Writer sub-agents via the Task tool. All use Bedrock inference.
6
Sub-agents execute — Researcher does web searches (Brave API), writes notes to /app/files/research_notes/. Data Analyst generates charts. Report Writer produces PDF via reportlab.
7
S3 upload + response — After run_query() completes, server.py uploads all files under /app/files/ to s3://<bucket>/sessions/<id>/. Lead agent's markdown summary + S3 paths returned as MCP response.

Agent Definitions

Lead Agent
Orchestrator — delegates all work via Task tool. Writes final markdown summary in response.

Key Lessons (AgentCore Runtime)

  • #7
    HTTP protocol contract: POST /invocations + GET /ping on port 8080. Wrong endpoints → 404 on every call.
  • #8
    Claude Code 2.x Bedrock env var: use CLAUDE_CODE_USE_BEDROCK=1. Old ANTHROPIC_BEDROCK=1 silently does nothing. Inject frozen boto3 credentials explicitly.
  • #9
    Non-root Dockerfile required: claude binary refuses --dangerously-skip-permissions as root. Add USER agent via groupadd/useradd.
  • #10
    Endpoint version pinning: after every update-agent-runtime, call update-agent-runtime-endpoint --agent-runtime-version N separately.
  • #11
    No Secrets Manager injection: load secrets via boto3 in Python at server startup. No task definition = no native injection.
  • #12
    Logs need OTEL: stdout is invisible. Add opentelemetry-sdk + OTLPLogExporter → localhost:4318.
  • #13
    No EFS support: files are ephemeral. Upload /app/files/* to S3 from server.py after each invocation.
  • #14
    Disable boto3 retries: set max_attempts=1 + read_timeout=1200. Default retries × timeout = 1800s of blocking.

Infrastructure Components

B
Amazon Bedrock — Inference profile us.anthropic.claude-opus-4-6-v1. Used by all 4 agents. IAM role: research-agent-agentcore-exec.

S3 Output Bucket — research-agent-output-*. Receives research notes, charts, PDF reports, and build artifacts. Keyed by session ID.
K
Secrets Manager — Secret research-agent/brave-api-key. Loaded by server.py at container startup via boto3, not via task definition injection.
E
ECR + CodeBuild — Image research-agent:latest (ARM64). Built via CodeBuild project research-agent-build from S3 context tarball.
P
mcp-proxy.py — Local Python stdio proxy. Handles MCP handshake instantly (no AWS). Forwards only tools/call to AgentCore Runtime. Registered in Claude Desktop config.
